# Science guide — normative modelling

This track takes you from **zero background** to a working understanding of
the morphometry and connectome methods used in this toolkit, with the
literature we rely on.

It is a teaching overview, not a substitute for the papers. Full citations:
{doc}`../references`.

## Core papers (start here)

1. **Rutherford et al., *Nature Protocols* 2022** — field framework + site adaptation  
2. **Ge et al., *Lancet Digital Health* 2024** — CentileBrain (MFP / GAMLSS)  
3. **Rutherford et al., *eLife* 2022** — large-scale PCN / braincharts models  
4. **Taylor et al., *Epilepsia* 2025** — IDEAS cohort (our worked example)
