# REPRODUCIBILITY.md — exact recipe to regenerate every published number

This document lists the exact software versions, dataset versions,
random seeds, and one-command recipes that regenerate every table,
figure, and reported number in the manuscript. Reviewers or
independent researchers should be able to reproduce the study from
this file plus the code in this repository.

## Software versions (frozen)

| Component | Version | Install |
|---|---|---|
| Python | 3.9 or 3.11+ (3.12 recommended) | System |
| R | 4.4.0 or 4.5.0 | System |
| R packages | mfp, gamlss, gamlss.dist | `install.packages(c('mfp','gamlss','gamlss.dist'))` |
| pcntoolkit | ≥ 0.27, < 1.0 for the CLI container; ≥ 1.0 works with native Python 3.11+ | `pip install "pcntoolkit>=0.27,<1.0"` (container) or `pip install "pcntoolkit>=1.0"` (native) |
| Python (analysis) | pandas, numpy, scipy, scikit-learn, matplotlib, python-docx | `pip install -r requirements.txt` (or see `normreport/pyproject.toml`) |
| Playwright | ≥ 1.30 (only for Figshare download) | `pip install playwright && playwright install firefox` |
| Apptainer / Singularity | ≥ 1.2 | System |

## Dataset versions

| Dataset | Source | Access | Version snapshot |
|---|---|---|---|
| IDEAS FreeSurfer stats + metadata | Figshare (via CNNP Lab page) | Public share-tokens in `ideas_data/README.md` | v3, downloaded 2026-08 |
| IDEAS resection percentages | CNNP Lab | Public | v1, Simpson *et al.* 2025 |
| CentileBrain pre-trained models | GitHub (CentileBrain/centilebrain) | Public clone | commit at time of scoring; MFP + GAMLSS `.rds` files |
| PCN Toolkit lifespan_DK_46K_59sites | PCN group | Public download | Rutherford *et al.* 2022 |

Raw Figshare downloads are regenerated by `ideas_data/fetch_figshare.py`
+ `ideas_data/fetch_resection.py`. The merged working table
`ideas_data/ideas_merged.csv` is produced deterministically by
`ideas_data/load_ideas.py`.

## One-command reproduction

Assumes prerequisites in `SETUP.md` are installed.

```bash
# 0. Clone this repo, then IDEAS + CentileBrain + PCN datasets/models
cd ideas_data && python3 fetch_figshare.py && python3 fetch_resection.py
python3 load_ideas.py && cd ..

# 1. Score with all three backends (~15 min total)
Rscript  score/score_centilebrain.R
Rscript  score/score_centilebrain_gamlss.R
python3  score/score_pcn_toolkit.py

# 2. Task-specific analyses (~10 min)
python3  score/analyze_scores.py               # Tasks 5 + 6 (MFP)
python3  score/classify_epilepsy.py            # Task 7
python3  score/resection_concordance.py        # Task 8
python3  score/compare_mfp_gamlss.py           # 2-way MFP vs GAMLSS
python3  score/compare_all_three.py            # 3-way SD / vs-IDEAS / resection
python3  score/pairwise_z_pearson.py           # all 3 pairwise Pearson r
python3  score/classify_all_three.py           # Task 7 AUC, all three, thickness
python3  score/hemispheric_lateralization.py   # Clinical extension
python3  score/ilae_outcome_prediction.py      # Clinical extension

# 3. mu_hat robustness (~5 min)
Rscript  score/mu_hat_cross_validation.R
Rscript  score/mu_hat_sample_size_sensitivity.R
python3  score/mu_hat_age_bin_sensitivity.py

# 4. Bootstrap CIs + power calculation
python3  score/bootstrap_lateralization_resection.py
python3  score/power_calculation_negatives.py

# 5. Manuscript artefacts (tables, figures, docx) — from manuscript/
cd manuscript
python3 _build_tables_docx.py       # Tables 1-6 + Supp S1 + Supp S3
python3 _build_figure_1.py          # Figure 1 (convergence)
python3 _build_figure_2.py          # Figure 2 (4-panel results)
python3 _build_figure_s2.py         # Supp Figure S2 (mu_hat)
python3 _build_graphical_abstract.py
python3 _build_abstract_docx.py     # Standalone abstract .docx
python3 _build_manuscript_docx.py   # Full manuscript .docx

# 6. Tool — install and unit-test
cd ../normreport
python3.11 -m pip install --user -e .   # 3.11+ for native pcntoolkit>=1
python3 -m pytest tests/                # expect 7/7
```

Total end-to-end wall-clock time on a workstation: ~35 minutes,
dominated by the SVC × 100 repeats in Task 7 and the PCN Toolkit
Bayesian scoring.

## Reproducing the container

```bash
cd normreport
APPTAINER_TMPDIR=$HOME/apptainer_tmp \
PROOT_TMP_DIR=$HOME/apptainer_tmp \
  apptainer build --fakeroot normreport.sif Singularity.def
# ~10 min. Expected ~3.5 GB .sif with 3/3 backends via pcntoolkit<1.0
# on rocker/r-ver:4.4.0 (Python 3.10). See normreport/CHANGELOG.md
# for the alternative Python 3.12 + pcntoolkit>=1.0 combination and
# its API-port caveat.
```

## Version stamps embedded in outputs

Every score CSV, PDF report, and figure produced by the tool embeds
a provenance block containing the git commit SHA, backend versions,
reference-cohort ID, and generation timestamp. Reviewers and
independent researchers can therefore cross-check any distributed
per-subject deviation score against the exact code state that
produced it.
